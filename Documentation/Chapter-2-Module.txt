   Full Example: 
Inventory Management and Its Importance 
Silver, Pyke, and Thomas (2016) emphasized that inventory management systems are essential 
in controlling stock levels, minimizing human error, and preventing tool loss. They explained 
that effective inventory systems help institutions avoid disruptions in operations by ensuring 
that required items are always available. 
This literature supports the need for a system in the automotive laboratory to prevent delays 
during hands-on exercises caused by missing tools. 
 
Database Systems in Inventory Applications 
Coronel and Morris (2016) described a database as an organized collection of structured 
information that is accessed and managed through a Database Management System (DBMS). 
They discussed how databases ensure data consistency, support multiple users, and allow 
secure retrieval of records. 
In the context of the proposed Tools Inventory System, the database will serve as the central 
storage of all transaction data such as stock-in/out, borrowing, and tool availability. 
 
 
 
 

=== PAGE 3 ===
 
Software Evaluation Standards – ISO 25010 
Pressman (2010) introduced the ISO 25010 model, which defines eight characteristics to 
evaluate software quality: functionality, usability, reliability, maintainability, efficiency, 
portability, compatibility, and security. 
This study uses the ISO 25010 standard to evaluate the Tools Inventory System after deployment 
to ensure its reliability and usability.

   Full Example: 
Development of a Laboratory Tools Tracking System 
Delos Reyes (2018) developed a tool-tracking system for a state university’s mechanical lab, 
aiming to address frequent tool losses and incomplete records. The system automated 
borrowing and returning records, reducing manual errors and improving student accountability. 
This is similar to the proposed study, but it lacked a formal system evaluation like ISO 25010. 
 
Web-Based Inventory System for Technical Colleges 
Chen (2020) created a web-based inventory system for a technical college’s engineering 
department. It allowed remote access to tool records and improved transaction logs and report 
generation. 
Unlike this study, the Tools Inventory System will be LAN-based, limiting access to the laboratory 
area only. 
 
RFID-Enhanced Tool Inventory Management 
Garcia and Liu (2019) implemented an inventory system that used RFID tags to track tools in real 
time. The system provided alerts for overdue tools and generated analytics on tool usage 
patterns. 
While RFID improves tracking, this feature is not included in the current system due to cost and 
technical constraints. However, it is considered a future enhancement.
